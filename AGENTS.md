# AGENTS.md

**Read [CLAUDE.md](./CLAUDE.md) first.** It is the single source of truth for this
repo — project overview, commands, architecture, the data pipeline, and common
workflows. Nothing in it is specific to one agent, so it is not duplicated here;
a copy would only drift.

For the estimate assumptions behind the "estimated" columns, see
[ESTIMATES.md](./ESTIMATES.md).

A few things that are easy to get wrong:

- `data/exact-daily.json` and `data/private/` are gitignored and must stay that
  way — `data/private/day-detail.json` contains local project paths.
  `data/daily-burn.json`, `data/meta.json`, and `data/pricing.json` are the
  committed, deployed files.
- The JSON files under `data/` are generated by `scripts/` — with one exception.
  Change the scripts, then re-run them; don't hand-edit the output.
- `data/pricing.json` is that exception: it is the hand-maintained rate card,
  and it is the *only* place a price lives. Edit it and re-run
  `scripts/build_daily_burn.py`; cost is derived on every run and never frozen,
  so the whole ledger reprices. A model with no entry there is priced as
  unknown, never zero.
- If you change an estimate pattern in `scripts/build_daily_burn.py`, update
  `ESTIMATES.md` in the same commit.
- Codex token attribution is a **high-water mark** per session, not a raw delta
  and not a reset-on-drop. A total below the session's running maximum is
  treated as an out-of-order or duplicated line and contributes nothing. The
  docstring in `scripts/extract_exact.py` records the session evidence for this;
  read it before changing the branch.
- The dollar figures are a **counterfactual** — what the usage would have cost
  at public API list prices. It ran on flat-rate subscriptions, so no one was
  billed it. Every dollar figure in the UI must carry the "at API list" pill
  (`BasisPill` in `app/page.tsx`) or a column header that says so. Absence of
  cost data is never `$0.00`; see the `CostKnowledge` table in CLAUDE.md.
